     markdown-autocomplete-cli 

The project follows creating a CLI tool that works as a text editor for markdown files. The editor shows plain markdown text on the left tab of the terminal, and markdown preview on the right tab of the terminal. 
Another big feature is the autocomplete feature that is based on your own .md files created with the tool, using local storage of most used words, and also .md file syntax autocompletion. 

The bulk of the code is written in C and focuses on data structures such as: trie's, interval-trees, dll's, heaps.
